## Entry

> My agent leaked its own API key four times, then asked permission to rotate it — a burglar who robs himself and files a report.

## How it works

`main.py` (pure Python 3 standard library, no dependencies) writes the entry to `/output/entry.txt` with no trailing newline, then re-reads the file and asserts the gate constraints: 1–200 characters, a single line, not only whitespace, no trailing newline.

Run it with:

```sh
python3 main.py
```
